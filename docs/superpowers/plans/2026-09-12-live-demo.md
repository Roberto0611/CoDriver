# Live Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/live` mode where Greedy and Nuez run the same fresh seed in real time, driven by the backend, and a judge can inject a closure or surge mid-shift and watch both agents react.

**Architecture:** Refactor the body of `sim.simular()` into a one-minute stepper (`reloj.Turno`) without changing results. A `LiveDemoSession` owns one offer stream plus two `Turno`s (greedy, nuez), advances both on `POST /live/tick`, injects the same `shocks.Shock` into both, and writes a per-session JSONL. The frontend accumulates each tick's snapshot into the same `TurnoData` shape the recorded replay already renders, so the map, trails, `Counters`, `Decisions` and `DecisionToasts` are reused unchanged.

**Tech Stack:** Python 3.11, FastAPI, pytest · React 19, TypeScript, MapLibre, Vitest.

**Spec:** `frontend/front-live-demo.md`

## Global Constraints

- No code file over 500 lines (`scripts/max_lines.py`, CI). `sim.py` is at 452 today.
- `python comparar.py 200` must print exactly the same numbers before and after (greedy $198, Nuez $264, +33.5%, 152/200). `tests/test_engine_golden.py` must stay green without regenerating baselines.
- Shock physics only via `shocks.py`. No Gemini in the decision loop; Nuez runs with `estrategia.BASE`.
- One offer stream per session, generated once, shared by both agents.
- Backend routes prefixed `/live`; the official `/decide` protocol is untouched.
- No WebSockets. Browser polls `POST /live/tick`, one simulated minute per tick, 500 ms at 1x.
- Frontend: follow `docs/ui-style-guide.md`. Keep the `/sim` layout. No emoji icons (use `ui/icons.tsx`), no new colors. Amber = surge/urgency, indigo = algorithm, emerald = money.
- Never write generated data into `frontend/public/`. Live JSONL goes to `cache/live/`.
- `frontend/src/contract.ts` is generated; don't hand-edit it.
- Tests never load `data/mty_graph.pkl` (not in git, absent in CI): geometry is injectable.

```python
class Turno:
    def __init__(
        self,
        cfg: ConfigTurno,
        politica: Politica,
        disrupciones: tuple[shocks.Shock, ...] = (),
        ofertas: list[Oferta] | None = None,
    ): ...

    t: int  # next minute to execute
    pos: int  # current map point index
    ruta: list[Parada]
    res: Resultado  # grows as minutes run
    disrupciones: tuple[shocks.Shock, ...]

    @property
    def terminado(self) -> bool: ...  # t >= cfg.duracion_min
    def activos(self) -> shocks.Activos: ...  # shocks.en(self.t, self.disrupciones)
    def inyectar(self, shock: shocks.Shock) -> None: ...
    def paso(self) -> None: ...  # runs minute self.t, then t += 1
    def cerrar(self) -> Resultado: ...  # rounding + llego_tarde, idempotent
```

```python
"""El demo en vivo: el mismo motor, dos agentes, un solo stream de ofertas."""

import json
from dataclasses import asdict
from functools import partial

import pytest

import rutas
import shocks
import valor
from backendruta.live_demo import SEED_ENSAYADO, LiveDemoSession, SesionTerminada
from contrato import ConfigTurno, Punto
from nuez import politica_nuez
from sim import politica_greedy, simular


def cfg(seed=SEED_ENSAYADO):
    tec = rutas.COORD_DE[rutas.puntos_de("Tec")[0]]
    return ConfigTurno(
        duracion_min=120,
        ancla=Punto("Tec", *tec),
        margen_min=10,
        vehiculo="moto",
        seed=seed,
        hora_inicio=14,
    )


def sesion(tmp_path, seed=SEED_ENSAYADO, name="s"):
    return LiveDemoSession(name, cfg(seed), tmp_path / f"{name}.jsonl")


def correr(s, hasta):
    snaps = []
    while s.snapshot()["minute"] < hasta:
        snaps.append(s.tick())
    return snaps


def decisiones(snaps, agente):
    return [d for snap in snaps for f in snap[agente]["frames"] for d in f["decisiones"]]


def test_greedy_y_nuez_ven_las_mismas_ofertas(tmp_path):
    snaps = correr(sesion(tmp_path), 120)
    ids = lambda a: [d["oferta_id"] for d in decisiones(snaps, a)]
    assert ids("greedy") == ids("nuez")
    assert len(ids("greedy")) > 50


def test_sin_shocks_el_final_es_el_de_simular(tmp_path):
    s = sesion(tmp_path)
    fin = s.end()
    assert fin["greedy"]["earnings_mxn"] == simular(cfg(), politica_greedy).ganado
    nuez = partial(politica_nuez, tabla=valor.para_turno(120))
    assert fin["nuez"]["earnings_mxn"] == simular(cfg(), nuez).ganado


def test_mismo_seed_mismo_shock_mismas_decisiones(tmp_path):
    def corrida(name):
        s = sesion(tmp_path, name=name)
        antes = correr(s, 30)
        s.shock("closure", 40, zona=0, calle="Constitución")
        return decisiones(antes + correr(s, 120), "nuez")

    assert corrida("a") == corrida("b")


def test_cierre_estira_los_tramos_de_los_dos(tmp_path):
    def tramos(con_cierre):
        s = sesion(tmp_path, name=f"c{con_cierre}")
        correr(s, 30)
        if con_cierre:
            s.shock("closure", 40, zona=0, calle="Constitución")
        snaps = correr(s, 70)
        return {a: [l for sn in snaps for l in sn[a]["new_legs"]] for a in ("greedy", "nuez")}

    libre, cerrado = tramos(False), tramos(True)
    for a in ("greedy", "nuez"):
        assert libre[a] != cerrado[a], f"el cierre no cambio las rutas de {a}"


def test_surge_sube_el_pago_de_las_ofertas_de_esa_zona(tmp_path):
    def pagos(con_surge):
        s = sesion(tmp_path, name=f"s{con_surge}")
        correr(s, 30)
        if con_surge:
            s.shock("surge", 30, zona=4, multiplicador=1.8)
        snaps = correr(s, 60)
        return {
            o["order_id"]: o["pay_mxn"]
            for sn in snaps
            for o in sn["offers_this_tick"]
            if o["pickup_zone"] == "Tec"
        }

    base, surge = pagos(False), pagos(True)
    assert base and base.keys() == surge.keys()
    assert all(surge[k] == pytest.approx(base[k] * 1.8, abs=0.2) for k in base)


def test_el_shock_queda_en_el_jsonl(tmp_path):
    s = sesion(tmp_path)
    correr(s, 30)
    s.shock("closure", 40, zona=0, calle="Constitución")
    correr(s, 31)
    s.end()
    eventos = [json.loads(l) for l in s.log.path.read_text(encoding="utf-8").splitlines()]
    tipos = [e["event"] for e in eventos]
    assert tipos[0] == "shift_start" and tipos[-1] == "shift_end"
    i = tipos.index("shock")
    assert eventos[i]["minute"] == 30 and eventos[i]["zone"] == 0
    despues = [e for e in eventos[i:] if e["event"] == "decision"]
    assert {e["agent"] for e in despues} == {"greedy", "nuez"}


def test_sesiones_nuevas_no_heredan_nada(tmp_path):

def test_no_hay_tick_ni_shock_despues_de_terminar(tmp_path):

    assert ultimo["greedy"]["result"]["ganado"] == ultimo["greedy"]["earnings_mxn"]
```

## Decisions (answered by JP, 2026-09-12)

1. **Closure is geographically accurate:** zone **0 (Centro)**, road **"Constitución"**, 40 min. The spec's "zone 2" is Valle and is wrong. Because pickups cluster around the Tec anchor, a Centro closure doesn't bite every seed, so Task 2 starts by finding the **rehearsed seed** (`SEED_ENSAYADO`): the lowest report seed ≥ 2000 where that closure at minute 30 changes the legs of both agents. Tests and the demo instructions use it.
2. **Surge preset:** zone 4 (Tec), ×1.8, 30 min.
3. **Real streets.** `main.py` already loads the graph as `G`; it is handed to the live router (`live_api.registry.usar_grafo(G)`), never loaded twice. `data/export_turno.geometria_de_tramos` gains an optional `grafo` parameter so both callers share one implementation.
4. **Execution:** subagent-driven, one fresh implementer per task, review per task.
